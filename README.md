# Amber Button Works

A standalone incremental clicker with generators, offline progress, autosave, and prestige sparks. Open `index.html` directly.

Based on the clicker structure of [remarkablegames/button-clicker](https://github.com/remarkablegames/button-clicker) by Menglin “Mark” Xu. MIT License; the original license is preserved in `LICENSE`. This edition changes the name, palette, progression data, layout, copy, and audio.
